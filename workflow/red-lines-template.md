# 红线清单模板

在 `prompts/start-meeting.md` 的议题区填写，沃格尔在立项闸门确认或补充。

```markdown
## 红线清单

| # | 红线项 | 类型 | 不可协商说明 |
|---|--------|------|--------------|
| 1 | （例：4 周内 MVP 上线） | 时间 | 逾期则方案无效 |
| 2 | （例：满足等保二级） | 合规 | 不达标禁止上线 |
| 3 | （例：禁止明文存储密码） | 安全 | 触碰即 Blocker |
| 4 | | 预算/人力/架构/… | |
| 5 | | | |
```

**类型**：时间 · 预算 · 人力 · 合规 · 安全 · 架构 · 依赖 · 战略

每位专家在输出「红线对照」表时引用上表编号，标注 ✅ 未触碰 / ❌ 触碰 / ⚠️ 边界情况。
